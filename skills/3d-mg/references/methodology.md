## 一、现状镜像（事实层）

**唯一目标**：在不重做任何账的前提下，把已有财报与经营数据重组为「按因果分组」的模型基期表。

**判据很简单**：只要这个数能从现有台账**算出来**，就不叫重做账；只有需要重新发生业务才能得到的数（重新盘点、重新开票）才叫重做。3D-MG 里没有一项属于后者。

### 1.2 口径确认单（九项，缺一不可）

在动任何模型之前，S1—S16 每一份都必须有口径确认单，由财务部起草、业务部门确认、**双方签字**。

```
资料名称：                资料编号：
责任部门：                              责任人：
一、指标定义：（例：材料成本 = 直接材料 + 外购件 − 运费 − 税）
二、归集时点：（入库 or 领用）
三、分摊规则：（按产值 / 工时 / 销量）
四、期间口径：（自然月 vs 会计月）
五、剔除非经常性项：（具体清单）
六、数据来源系统与表名：
七、提取频率：
八、口径生效期：                至
九、变更记录：
【业务部门确认签字】         【财务部门确认签字】
```

**纪律**：签字率低于 100% 不得进入建模。**不允许会后邮件往返确认**，开单次集中会（2 小时）一次性签完。

### 1.3 六条禁止重复工作

这些动作是导致「周期过长、被怀疑重做审计」的根本原因，必须制度性禁止。

| 禁止 | 为什么 | 替代做法 |
|---|---|---|
| 重新编制财务报表或做模拟账 | 与审计口径冲突，无管理增量 | 直接调用现有月报 |
| 重新盘点资产、重新认定收入 | 属审计职能 | 向财务申请专项口径说明 |
| 全量订单数据二次加工为分析模型 | ERP 已有标准报表 | 配置 ERP 报表参数 |
| 要求各事业部重新填报数据台账 | 基层负担最重、口径最难统一 | 从现有系统取数 |
| 访谈全部管理人员 | 超出必要范围 | 每模型访谈 6—8 名关键角色 |
| 追求「覆盖全部价值链」 | 违反关键少数原则，必然失败 | 只建 1—2 条链路 |
| 在模型未定稿前对外汇报数字 | 易被质疑，造成信任损失 | 内部定稿后再汇报 |
| 建立独立于现有系统的信息系统 | 重复投资，数据同步难持续 | 用 Excel + 现有 ERP/BI |
| 由外部咨询独立完成全部建模 | 业务知识在内部，外部无法建模 | 内部主导，外部做方法论支持 |

### 1.4 实操六步

**步骤一：立组授权（0.5 天）**
集团总经办签发一页纸授权书，明确组长、组员、建模型范围、完成时限、汇报对象。
*失败信号*：没有一把手签发的书面授权 → 后续步骤不得启动。

**步骤二：口径确认（3—5 天）**
对 S1—S16 逐项出具口径确认单，集中会一次性签署。
*失败信号*：签字率< 90% → 不得进入步骤三。

**步骤三：基期建模（5—8 天）**
按六段成本结构重组数据，建立 T-12 期基期表。

| 行号 | 项目 | 上年同期 | 本期 | 变动额 | 变动率 | 占收入比 | 数据来源 |
|---|---|---|---|---|---|---|---|
| 1 | 营业收入 | | | | | 100% | S1 |
| 2 | 减：材料成本 | | | | | % | S2 |
| 3 | 减：人工成本 | | | | | % | S2 |
| 4 | 减：制造费用（固定） | | | | | % | S2 |
| 5 | 减：制造费用（变动） | | | | | % | S2 |
| 6 | 减：物流仓储成本 | | | | | % | S11 |
| 7 | 减：质量损失成本 | | | | | % | S9/S10 |
| 8 | 减：共享资源分摊 | | | | | % | S15 |
| 9 | **毛利额** | | | | | % | 计算 |
| 10 | **毛利率** | | | | | —— | 计算 |
| 11 | 折旧 | | | | | % | S2 |
| 12 | 销售费用 | | | | | % | S1 |
| 13 | 管理费用（含研发） | | | | % | S1/S13 |
| 14 | **EBIT** | | | | | % | 计算 |

*失败信号*：任一成本段占收入比与上年差异 > 3pp 且无法解释 → 口径不一致，退回步骤二。

**步骤四：三段归因（2—3 天）**

| 归因维度 | 计算方式 |
|---|---|
| 价格变动影响 | （本期单价 − 上期单价）× 本期销量 |
| 销量／结构变动影响 | （本期毛利率 − 上期毛利率）× 上期收入 |
| 材料成本影响 | − 材料成本率变动 × 本期收入 |
| 人工成本影响 | − 人工成本率变动 × 本期收入 |
| 制造费用影响 | − 制造费用率变动 × 本期收入 |
| 质量损失影响 | − 质量损失率变动 × 本期收入 |
| 分摊影响 | − 分摊率变动 × 本期收入 |
| **合计（须等于毛利率变动）** | |

**强制校验**：合计与实际毛利率变动差异 < 0.05pp。超限说明有未纳入项，**必须查明才能定稿**。
*这是本方法最重要的一条数据质量红线。*

**步骤五：异常项标注（1—2 天）**

| 异常类型 | 阈值 |
|---|---|
| 单项成本率变动 | 绝对变动 > 1.0pp |
| 单项成本率超预算 | 超预算 > 1.0pp |
| 单客户毛利跌幅 | > 20% |
| 单客户收入跌幅 | > 15% |
| 稼动率偏离目标 | > 5pp |
| 质量损失率上升 | > 0.5pp |
| 客户年降超授权 | 超授权 0.5pp 以上 |
| 应收账款周转恶化 | DSO 上升 > 10 天 |

*失败信号*：归因写「其他」「市场原因」「客观因素」→ **打回重写**。归因必须具体到「哪个变量、动了多少」。

**步骤六：定稿封版（1 天）**
财务部、战略 MTP 部、经营分析部三方签字，版本号 V1.0，标注生效期。
*失败信号*：未签字版本一律无效，后续因果模型不得引用。

### 1.5 动态更新

**月度（0.5 人·天，固定四步）**：ERP 导出四张台账（1h）→ 刷新基期表当期列（1.5h）→ 跑阈值筛查（0.5h）→ 归档推送（0.5h）。

**月度四条禁止**：不改口径、不改系数、不重估因果、不新增数据源。
**红线**：任一检查项不通过，不得封版，不得作为下月基期。

**季度（+1.5 人·天）**：客户结构分析（Top 20 重算毛利）／单产品线盈亏平衡点重算／与 MTP 对比输出偏差归因／口径有效性抽查（抽 3 项，防口径被悄悄改掉）。

**年度（+15—20 人·天）**：见 SKILL.md 迭代机制。

## 二、因果镜像（关系层）

### 2.1 建模五步法

```
第1步 定链路    明确建模的价值链范围（一句话，不超过 20 字）
第2步 画因果图  变量（节点）+ 因果关系（箭头）+ 正负号 + 弹性量级
第3步 定口径    每个节点的计算公式、数据来源表、责任人
第4步 估弹性    用历史数据回归估算；数据不足则用结构化访谈
第5步 定阈值    每个关键变量设预警线与治理动作
```

**三条硬约束**：
- 第 4 步**不允许跳过**。没有弹性系数的因果图只能用于讨论，不能用于决策。
- 第 5 步**必须落到「动作」**，不能停在「关注」。
- 每步结束都产出可交付物，不产出则该步不算完成。

### 2.2 统一符号规范

| 符号 | 含义 | 要求 |
|---|---|---|
| `→` | 正向因果 | 必标弹性量级 |
| `⊣` | 负向因果 | 必标弹性量级 |
| `[高]` | \|e\| > 0.3 | 影响集团级，月度跟踪 |
| `[中]` | 0.1 < \|e\| ≤ 0.3 | 影响板块级，季度跟踪 |
| `[低]` | \|e\| ≤ 0.1 | 背景参数，不单独跟踪 |
| `⊙k` | 第 k 个内部负外部性节点 | 必须附冲突说明与裁决层级 |
| `Δt=nm` | 传导时滞 n 个月 | 决定预警提前量 |
| `?=专家判断` | 因果方向来自访谈 | 必须记录来源人与日期 |

### 2.3 置信度分级（强制标注）

| 标注格式 | 条件 | 使用边界 |
|---|---|---|
| `回归 R²=0.8` | 样本 ≥24，R²≥0.6，p<0.05 | 可直接支撑经营决策 |
| `回归 R²=0.5` | 样本 ≥12，R²≥0.4 | 需业务确认 |
| `专家估计·已验证` | 2 人以上提及 | 需业务确认后使用 |
| `专家估计·待验证` | 仅 1 人提及 | 仅供讨论 |
| `背景参数` | \|e\| ≤ 0.1 | 不单独跟踪 |

**为什么必须标注**：管理层有权知道「这个数字有多可信」。混淆置信度是分析工作最严重的失职之一。

### 2.4 线性因果网络图（分层结构）

**第一层外生变量**（不受企业决策控制）：E1 原材料价格／E2 能源与物流／E3 汇率利率／E4 需求景气／E5 竞争强度／E6 政策合规／E7 突发外部事件

**第二层决策变量**（企业可控）：D1 采购策略／D2 产品组合与定价／D3 报价响应策略／D4 产能与稼动率／D5 研发投入方向／D6 客户结构／D7 质量控制投入／D8 库存水位

**第三层中间传导变量**（模型核心）：M1 单位材料成本／M2 单位制造成本／M3 质量损失成本／M4 物流成本／**M5 综合毛利率（核心枢纽）**／M6 订单量／M7 稼动率／M8 应收账款与资金占用／M9 新项目爬坡／M10 研发费用率／M11 年降接受度／M12 共享资源分摊系数

**第四层集团结果变量**：O1 营业收入／O2 毛利额与毛利率／O3 EBIT／O4 经营性现金流／O5 ROIC／O6 目标达成率

**主干链路**：
```
E1→M1 材料成本 → M5 → O2 毛利额 → O3 EBIT → O4 现金流 → O5 ROIC
E2→M4 物流成本 ↗
E4→M6 订单量 ↗                M7 稼动率 → M2 固定摊薄（非线性放大）
M12 共享资源分摊 ↗            M8 应收账款 → 反向约束接单能力
M9 新项目爬坡 → M7 稼动 → M2（长期改善杠杆）
```

### 2.5 内部负外部性清单（⊙节点，决策时必看）

| 编号 | 节点 | 正外部性 | 负外部性 | 裁决层级 |
|---|---|---|---|---|
| ⊙1 | D1 采购锁价 | 采购部成本指标达成 | 生产部承担价格波动风险 | 集团采购委员会 |
| ⊙2 | D8 库存水位 | 销售交付及时、避免缺货 | 财务占用现金、减值风险 | 集团 CFO |
| ⊙3 | D6 客户结构 | 收入规模增长 | 优质客户被低价订单挤占 | 集团经营委员会 |
| ⊙4 | D3 提价 | 毛利率提升 | 市场份额与销量下滑 | 集团经营委员会 |
| ⊙5 | D7 质量投入 | 缺陷损失下降 | 检验成本上升、交期拉长 | 集团质量委员会 |
| ⊙6 | M7 稼动率 | 单位固定成本下降 | 设备折旧压力、人员闲置显性化 | 集团制造委员会 |
| ⊙7 | M5 毛利率 | 利润达成 | 可能来自弃单，规模指标未达成 | 集团总经办 |
| ⊙8 | M12资源分摊 | 分摊方成本可接受 | 被分摊方利润被侵蚀、抵触 | 集团财务+事业组合计 |

**⊙1 尤其重要**：锁价比例这个决策由采购部做出，但价格波动风险落在生产部。**这类冲突现有体系无法裁决，必须摆到集团层面。**

### 2.6 关键少数原则

只保留对集团级结果有显著弹性（|e| > 0.1）的变量，其余降级为背景参数。

**模型规模上限**：因果图节点 ≤ 25 个、边 ≤ 40 条。超过说明建模范围失控。

## 三、推演镜像（选择层）

### 3.1 与 MTP 的关系：复用而非重做

| 复用对象 | 用途 | 是否重做 |
|---|---|---|
| MTP 战略目标与方向 | 推演的目标边界 | **不重做** |
| MTP 年度财务目标 | 基准情景输入 | **不重做** |
| MTP 业务布局与产能规划 | 推演的结构约束 | **不重做** |
| MTP 重点项目清单 | 模型二的对象 | **不重做** |
| MTP 资源投入计划 | 模型五的分摊对象 | **不重做** |

3D-MG 对 MTP 是「读取」关系，只补五样东西：① 目标的可实现条件 ② 关键变量敏感度排序 ③ 目标脆弱点 ④ 替代路径 ⑤ 偏差早期信号。

**边界**：只修正MTP 的「假设」和「节奏」，不修正「方向」和「承诺」。战略方向与业务布局调整一概不参与。**越界会导致失去管理层信任。**

### 3.2 四类情景

| 情景 | 设定规则 | 用途 |
|---|---|---|
| 基准 | 关键变量取「近3年中位数 + 已签订约确定项」 | 年度计划基准 |
| 保守 | 关键变量取「近3年P25 + 已知负面因素」 | 压力测试 |
| 乐观 | 关键变量取「近3年 P75 + 已知正面因素」 | 机会识别 |
| **治理干预** | 基准上叠加「**已批准**的管理改善动作」 | **决策专用** |

**治理干预情景是本方法独有的**，也是核心价值：
```
基准情景= 什么都不做，会怎样
治理干预情景     = 做了 M1/M2/M3/M4 四项改善，会怎样
差额             = 治理动作的价值（可量化、可考核）
```
⚠️ 治理干预情景**必须是「已批准的动作」**，不是愿望清单。没有责任人、没有预算、没有时间表的改善动作，不得进入情景计算。

**五条纪律**：保守与乐观情景不得反向操作；变量间不做相关性假设（除非有数据支持）；只放已批准动作；每情景必须算出 EBIT 绝对值；四情景须一次性同时呈现（分次呈现会导致选择性解读）。

### 3.3 敏感性分析

| 方式 | 做法 | 回答什么 | 用量 |
|---|---|---|---|
| 单变量 | 每次只动一个变量 ±10%/±20% | 每个变量单独值多少钱 | 5—8 变量 × 4 档 = 20—32 次 |
| 双变量交叉 | 两个关键变量同时变动（3×3 矩阵） | 变量间是互补还是替代 | 选 2 对最相关变量 |
| 龙卷风图排序 | 按影响幅度排序 | 哪个变量最值得管 | 一次绘图 |

**三条纪律**：不做全变量扫描（30 个变量全扫= 不可用，守住前 8 名）；弹性系数必须来自已建模型，不允许临时假设；结论必须落到「管哪个变量」。

**输出模板（关键结论）**：
> 本年 EBIT 的成败**主要取决于两个变量**：稼动率（波动 3.72pp）与新项目达产数（波动 2.28pp）。原材料成本波动仅 1.24pp，相对次要。**管理注意力应集中于产能利用率与新项目爬坡，而非原材料采购。**

### 3.4 MTP 可实现条件反推表（最核心的输出物之一）

这张表把「目标定得合不合理」这个反复争论、永远吵不出结果的问题，转成「条件是否成立」这个可以逐项验证的事实问题。

| MTP 目标 | 目标值 | 达成所需条件（须同时满足） | 现状值 | 缺口 | 可行性 |
|---|---|---|---|---|---|
| 营业收入 78,000 万 | 78,000 | 稼动率≥85% 且 新项目≥5 个达产 且 无 Top3 客户流失 | 稼动率 78%、在研 5 个（未达产） | 见左 | **可行（紧）** |

## 四、闭环修正机制

### 4.1 四个节拍

| 节拍 | 频率 | 动作 | 责任 | 人·天 |
|---|---|---|---|---|
| ① 现状镜像 | 月度 D+1—D+5 | 刷新基期表、算偏差、筛异常 | 经营分析部 | 0.5 |
| ② 因果定位 | 偏差后 2 周内 | 用模型反算「偏差里多少来自哪个变量」 | 经营分析部+业务 | 0.5 |
| ③ 推演修正 | 月度/季度 | 判断目标是否需要修正 | 战略 MTP 部+财务 | 0.5/3 |
| ④ 修正落地 | 决策后 2 周内 | 管理层拍板 → 修正 MTP | 集团总经办 | 决策会 1 次 |

**关键约束**：节拍①—③ 全部可由职能部门完成，**只有节拍④ 需要管理层介入**。这是「3D-MG 不增加管理层负担」的关键设计。

### 4.2 偏差三分类（修正前必须先分类）

| 归因类型 | 判断标准 | 修正类型 | 动 MTP 吗 |
|---|---|---|---|
| **执行型** | 目标合理，变量值不利是因为执行不到位 | 纠偏动作 | **不动** |
| **外生型** | 目标合理，变量值不利是因为外部变化 | 预案执行+ 条件化目标 | **条件性动** |
| **设定型** | 即使变量都达到预期，模型测算仍无法达标 | 目标修正 | **必须动** |

### 4.3 六条修正规则

1. **先分类，再动作。** 未经归因分类的偏差不得进入修正流程。这能过滤掉 60%—70% 的假偏差。
2. **执行型偏差用管理解决，不用改目标解决。** 把目标改低来消化执行不到位，是治理腐化的起点。
3. **外生型偏差修「条件」，不修「数字」。** 正确做法是把 MTP 改为「若原材料综合涨幅超过 X%，则毛利率目标调整为 Y%」——**条件化目标**，而非直接下调目标。
4. **设定型偏差必须上会，且必须带证据。** 必须附：模型版本、弹性系数来源、历史数据区间、已排除因素。**没有证据的「做不到」不构成理由。**
5. **修正必须留痕。** 修正编号、触发原因、修正内容、决策人、决策日期、生效期。
6. **修正不得触碰战略方向。**

### 4.4 触发阈值与升级路径

| 级别 | 触发条件 | 处理方式 | 审批层级 |
|---|---|---|---|
| T1 观察级 | 单月单指标偏差 < 1.0pp 且无连续性 | 记录在月度看板，**不动 MTP** | 经营分析部自主 |
| T2 关注级 | 单月偏差 ≥ 1.0pp，或连续 2 月同向 ≥ 0.5pp | 启动因果定位；外生型纳入季度修正 | 财务+战略 MTP 联合 |
| T3 修订级 | 季度累计偏差 ≥ 2.0pp，或判定为设定型 | 正式提交《MTP 修正建议书》 | 集团总经办/经营委员会 |

**反向通道（必须设计）**：若修正后连续 2 个月实际仍偏离修正后的目标，**须回退到 T3 重新评估**。这条通道防止「修正—再偏差—再修正」的无限循环。

### 4.5 防止「滚动修正变成年年重做」的四道防线

| 防线 | 做法 |
|---|---|
| **留痕 + 版本管理** | 修正唯一编号（MTP-R-年份-序号）、全量保留、季度升小版本（V1.0→V1.1）不重新编号 |
| **修正类型配额** | 条件性调整不限；**目标值修正每季度最多 1 次**；**战略方向调整每年最多 1 次** |
| **模型稳定性承诺** | 修正期间只改参数不改结构；结构变更只在年度校准窗口；修正记录必须引用模型版本号 |
| **修正效果回检** | 修正后 2 个月回检偏差是否收敛；年度回检「上次假设的实际值是多少」；回检模型偏差累积 |

**配额的作用**：把「改目标」变成一件稀缺的、需要额外论证的事。这比任何说教都有效。

**回检的核心作用**：让每次修正都变成对模型能力的检验。如果三年下来预测一直很准，说明因果链找对了；一直偏，说明模型在自欺欺人。

## 模型一：原材料—成本—报价—毛利传导

### 建模方法

**核心公式（四层）**

```
第一层 成本传导
  M1_t = M1_{t-1} × (1 + Σ_j P_j × β_j × λ_j)
  P_j = 物料 j 价格变动率
  β_j = 物料 j 成本权重（占材料成本比）
  λ_j = 采购滞后系数（当月采购比例，如 0.4）

第二层 毛利即时效应（未经调价）
  ΔM5_immediate = − ΔM1 / 收入

第三层 调价响应
  t' = t + Δt，Δt = 报价决策时滞（月）
  ΔP_response = θ × max(ΔM1, 0)     ← 仅成本上升触发提价，成本下降不主动让利

第四层 调价后的量价效应
  Δ收入 = 提价幅度 × 订单量 − 价格敏感度 × 订单量
  Δ毛利 = Δ收入 − ΔM1 × 出货量
```

**关键参数**

| 参数 | 含义 | 估算法 |
|---|---|---|
| β_j | 物料权重 | 直接取采购金额占比 |
| λ_j | 采购滞后系数 | 当月采购额 ÷ 期间总采购额 |
| Δt | 报价响应时滞 | 历史调价事件日期回归 |
| θ | 成本转嫁比例 | 历史调价幅度 ÷ 同期成本上升幅度 |
| κ | 价格敏感度 | 历史「提价幅度 → 订单量变化」回归 |
| q | 订单流失率 | 1 − 订单量变化比例 |

**为什么首选**：数据 100% 现成（S3 采购台账 + S1 利润表），因果关系是物理意义上的成本传导（最清晰），结论最直观（涨多少→少赚多少），见效最快（第一次月度更新就能出结论）。

### 风险与规避

| 风险 | 后果 | 规避|
|---|---|---|
| 历史数据 < 24 月 | 回归不可靠 | 用季度数据（需 8 季度）；仍不足则改访谈并标注低置信度 |
| 原材料品种 > 20 种 | 模型复杂到无法维护 | 只取金额占比前 8 位，其余合并为「其他」 |
| 采购价与现货价脱节 | 用外部行情估弹性失真 | 优先用实际采购均价；外部行情仅作前瞻预警 |
| 提价后订单量数据滞后 | κ 估不准 | 强制设定「观察期 60 天」，未到期事件不纳入回归 |
| 商务不愿提供调价记录 | 关键数据缺失 | 从报价单系统取；总经办明确「只纠偏不追责」 |
| 算出「应提价」但商务不执行 | 结论空转 | 提价规则写入商务年度授权表，与预算授权同层级 |
| 忽略稼动率对固定摊的放大 | 高估毛利改善 | M2 必须区分固定/可变，稼动率单列一条边 |

### 优先级判定

**必须建（满足任一）**：① 材料成本占收入比 > 35%；② 过去 24 个月出现过单季材料成本率波动 > 3pp；③ 有年度调价谈判机制且毛利受成本影响显著；④ 一把手明确要求。

**可暂缓**：材料成本占收入比 < 15% 且波动 < 1pp——此时材料不是主要矛盾。

## 模型二：新项目全生命周期盈亏传导

### 建模方法

按生命周期五阶段（定点→研发→量产→爬坡→稳态）分别建盈亏函数，串联成现金流曲线。

```
定点（T0）：参数 = 预计总投资 I、预计年销量 V、预计单价 P
  ★必须乘以爬坡达标率φ（历史统计值）做校准，否则系统性高估
研发（T0+0~12月）：参数 = 研发投入 R、里程碑通过率
量产（T0+9~15月）：参数 = 良率 Y(t)、产能爬坡斜率 r
爬坡（T0+12~24月）：★盈亏最脆弱阶段
  Q(t) = Qmax × (1 − e^(−r·t))
稳态（T0+24月以后）：参数 = 稳态出货 Qmax、单位成本 C∞

盈亏函数：
  研发期现金流 = −R × 分期投入
  爬坡期现金流 = [Q(t)×(P − C(t)) − 固定费用] × Δt
  稳态现金流 = [Qmax × (P − C∞) − 固定费用] × 12

  盈亏平衡点 T_BE = 累计现金流 = 0 的时间点
  全生命周期盈亏 = 稳态年现金流 × 存续年限 − 总投资

三道关口量化标准：
  关口一（立项）：全生命周期 ROI ≥ 集团门槛 且 NPV > 0
  关口二（量产前）：良率爬坡曲线达标率 ≥ 70%
  关口三（爬坡末）：实际 Q(t) 与计划偏差 ≤ 20%
```

**关键创新点**：必须把「爬坡速度 r」和「良率 Y」作为**独立决策变量**建模，而非按经验值代入。因为新项目亏损最常见的原因不是卖点错误，而是**爬坡慢于预期**（把固定费用摊到不足产量的产出上）。

## 模型三：质量缺陷—损失—索赔溯源

### 建模方法

建立「缺陷类型 → 发生环节 → 后果（返工/报废/停线/降级/索赔/流失）」的溯源矩阵，把质量成本从「一个总数」拆解为「按原因可归因、可管控、可分摊」的结构化成本。

```
质量损失总额 = 内部损失 + 外部损失 + 隐性损失
  内部损失 = 返工工时成本 + 报废材料成本 + 停线损失 + 降级销售损失
  外部损失 = 客赔金额 + 退货物流成本 + 客户认证降级损失
  隐性损失 = 客户流失毛利 + 未来订单份额损失（折算）

单缺陷类型年度损失 = 缺陷年发生量 × 单件平均损失
缺陷年发生量 = 出货量 × 缺陷率 DRI

责任可归因率 α = 可明确到供应商/工序/部门的损失 ÷ 总损失
  ★α 是本模型最关键的指标：α 越高，损失越可管控
```

**责任分摊（仅用于责任认定，不用于个人考核）**：供应商 → 采购部索赔（商务追偿）／内部工序 → 工艺/设备/人员（改进导向）／设计 → 研发（DFM 从源头改进）。

## 模型四：客户年降—报价—合同毛利动态

### 建模方法

以「客户合同条款」为起点，模拟年度降价谈判中「年降幅度 × 订单量变化 × 成本应对」三者对客户级毛利的综合影响。

```
客户级毛利贡献 = 订单量 Q ×（单价 P − 单位变动成本 VC）
单价 P_t = P_{t-1} × (1 − 年降幅度 r) × (1 − 一次性降价 e)
单位变动成本 VC_t = VC_{t-1} × (1 + 成本上升 c)

毛利贡献变化：
  ΔG = Q×(ΔP) + ΔQ×(P − VC) + ΔQ×ΔP − Q×(ΔVC)
     ├ 价格效应 ┤   ├ 销量效应 ┤  交叉项     └ 成本效应 ┘

谈判底线：
  最低可接受报价 P_min = VC + (固定费用分摊 ÷ Q) + 目标毛利率
  若 P_min > 客户可接受上限 → 明确弃单，避免隐性亏损订单
```

**关键认知**：年降本身不可怕，**可怕的是「年降 + 订单量下降 + 成本上升」三者叠加**。模型价值在于把三种效应分离，找出真正的亏损来源。

**成本分摊三级法**（本模型最大技术门槛）：

```
一级：直接可分（材料 + 专属物流 + 专属模具）    → 精确
二级：按产值比例分摊（变动制造费用）            → 合理
三级：按销量或工时分摊（固定费用）              → 近似
分摊后客户级毛利 = 收入 − 一级 − 二级 − 三级
★分摊比例一旦确定须固定，不得逐月变动
```

## 模型五：集团共享资源跨板块传导

### 建模方法

把集团共享资源视为「跨板块的价格信号」，追踪其在各板块间的传导与分摊。

```
集采传导：
  板块成本影响 ΔC = (P_group − P_self) × 用量
  节约归属 = 集团 ÷ 分摊系数 α  或  板块自得（取决于分摊规则）
  ⊙8 分摊规则直接决定各板块利润，是争议根源

资金池传导：
  A 让出资金给 B
  → A 利息收入减少 ΔI = 资金额 ×（内部资金收益率 − 外部融资成本）
  → B 财务费用减少同等金额
  → 集团整体：总利息支出不变，但资金使用效率提升
  ★集团价值 = 池的价值 = 差额 × 池规模

研发平台传导：
  集团研发投入 R = 基础平台（共通）+ 定向开发（专属）+ 平台溢出
  共通部分按约定分摊（用量法/收入法/均摊）
  专属部分不进分摊，但共用平台的「搭便车」需通过收费解决
  跨板块技术溢出难以计价，只能定性标注

产能互济传导：
  A 承接 B 的溢出订单 → A 稼动率↑（固定摊薄）
  B 减少外协加工费 → B 成本↓
  集团整体产能利用率↑，但 A 的产能被占用，需计算机会成本
```

**关键认知**：本模型不解决「要不要集中」这个战略问题，只解决「集中之后钱怎么算」这个**分配公平性问题**。分配不公平是集团管控失效的最常见内因。

**可暂缓**：完全松散型组织（无共享资源）、单一业务板块。

## 模型六：重大外部冲击预警

### 建模方法

对已识别的外部冲击，预先建立「冲击类型 → 受影响变量 → 受影响板块 → 影响量级 → 预警信号 → 应对动作」的传导映射库。

```
影响量级 = 受影响产能或销量 × 单位毛利变化 × 持续月数

乘数因子 k：
  k = 1.0   直接且完全传导
  k = 0.6   直接但可通过替代/切换供应商缓释
  k = 0.3   间接影响
  k = 2.0   二次放大效应（如断供导致客户流失）

预警分级：
  L1 观察级：影响 < 集团年毛利 0.5%        → 持续监控
  L2 关注级：0.5% ≤ 影响 < 2%              → 启动预案准备
  L3 警告级：2% ≤ 影响 < 5%                → 启动预案执行，管理层会议
  L4 危机级：影响 ≥ 5%                     → 集团应急机制启动

预警提前量 = 事件可观测信号出现时间 − 实际影响显现时间
  ★核心价值：把提前量从 0 拉到 1—6 个月
```

**三类冲击场景的标准传导链**

```
场景一 原材料暴涨（如铜价 +30%）
  信号：期货连续 15 日上行 + 现货月均价环比 >8%
  链：M1 成本↑ → M5 毛利↓ → 报价联动 → 订单量变化 → 稼动率变化
  缓释：锁价比例、替代材料、涨价传导、减产保价

场景二 海外扰动（关税/制裁/物流中断）
  信号：目的国关税政策公告 / 港口拥堵指数 / 船期取消率
  链：海外订单↓ 或 到岸成本↑ → 收入与毛利双向承压
  缓释：产地转移、库存前置、转内销、国内客户承接

场景三 供应链风险（关键物料断供）
  信号：供应商产能公告 / 同行涨价 / 交期异常延长 / 单一来源预警
  链：产能缺口 → 交付延期 → 客户罚款 + 客户流失
  缓释：双源认证、库存安全水位、代工厂切换
```

## 模型七：结构化专家访谈因果建模

### 建模方法

当历史数据不足以支撑回归时，通过标准化访谈采集「隐性因果关系」，再用量级估计与三角验证转化为可用系数。

**为什么它是最重要的一个**：前六个模型解决「有数据的部分」。而在真实企业中，**决定经营结果的因果链里，30%—50% 从未在任何台账留下痕迹**：

- 「换这个供应商会导致良率下降」——无历史数据，因为从没换过
- 「这个客户的价格是战略性的，不能单独测算」——无独立成本数据
- 「设备故障会连带影响隔壁产线的排产」——从未被记录
- 「这个岗位换人会导致交付周期延长 2 周」——隐性知识

这部分知识目前只存在于少数资深人员脑中。**人员一走，链路就断。**

**六步流程**

```
第1步 选人   6—8 名关键角色，覆盖「做决定的 + 干活的 + 受影响的」
        典型构成：事业部总经理 1 + 生产/采购/销售/质量负责人各 1
                  + 财务对接人 1 + 一线班组长 1 + 离职/退休专家 1
        ★必须包含 1 名「了解历史但不在职」的人员，可发现组织已遗忘的因果

第2步 问卷   提前发结构化问卷（3—5 题预热，不含敏感信息）

第3步 访谈   每场 60—90 分钟，全程录音（经本人同意）

第4步 编码   录音转录 → 逐句编码为因果关系
        格式：变量A → 变量B | 符号 | 量级 | 时滞 | 置信度 | 来源人

第5步 三角验证  同一关系至少由 2 名受访者提及，或有 1 份数据佐证
             仅 1 人提及的标为「待验证」

第6步 固化    通过验证的关系进入因果图，注明「专家判断」与访谈日期
```

**因果五问法（访谈提纲核心）**

| 问 | 想获取的信息 |
|---|---|
| ① 「去年 XX 指标变化，您认为主因是什么？**为什么是它而不是别的？**」 | 主因果识别 + 排除替代解释 |
| ② 「这个原因会连带影响哪些其他环节？**能举例说明吗？**」 | 传导链 |
| ③ 「这个影响大概有多大？占多少比例？」 | 量级估计 |
| ④ 「从您发现到实际影响结果，大约间隔多久？」 | 传导时滞 |
| ⑤ 「如果这个原因变化 ±10%，结果会怎样？」 | 弹性量级直觉 |

**量级估计转换规则（定性 → 可用数字）**

| 受访者表述 | 转换量级 | 使用限制 |
|---|---|---|
| 「几乎没影响」「基本无关」 | \|e\| ≤ 0.05 | 降级为背景参数，不入模型 |
| 「有点影响」「有一些」 | \|e\| = 0.1 | 标低置信度，需后续验证 |
| 「影响比较大」「挺关键」 | \|e\| = 0.2 | 标中置信度 |
| 「影响非常大」「决定性的」 | \|e\| = 0.4 | 标中置信度，可优先验证 |
| 「一变就全盘改变」 | \|e\| ≥ 0.6 | 标高置信度，**必须数据验证后才可进决策** |

⚠️ **所有访谈得出的系数在获得至少 2 年数据验证前，一律标注「专家估计」，可用于讨论与假设，不可直接用于经营决策。** 这是本模型的学术诚实底线。

**高价值隐蔽资料**：作业指导书里常写着「不得同时开启两台设备」这类隐性约束——这类「禁令」本身就是因果关系；历史异常案例记录则直接提供因果链的实证。

### 风险与规避

| 风险 | 规避 |
|---|---|
| 受访者不愿讲真话 | 匿名化处理；不追问责任归属；不与考核挂钩（**明文承诺**） |
| 只访谈在职管理者 | **必须纳入 1—2 名离职/退休专家** |
| 专家判断被当作硬数据 | 全部标「专家估计」，两年数据验证后才可升级 |
| 访谈变成领导宣讲 | 班组长访谈单独进行，不与管理层同场 |
| 编码主观、结论不可复现 | 统一编码模板，同一关系由 2 人独立编码后比对 |
| 关系数量失控（>200 条） | 按弹性过滤，只保留 \|e\|≥0.1（通常剩 30—50 条） |
| 涉及商业机密，录音受限 | 敏感会议只做笔记不留录音；笔记仅限项目组 |

### 优先级判定

**模型七应当最先启动（不是最后）**，理由：① 数据充足度最高（不需要任何台账，只需要人的时间）；② 人力门槛最低（6—8 人 × 1.5 小时 = 10 小时）；③ 边际价值最高（找到 1 条高弹性隐性关系，可能解决前六个模型都解决不了的问题）；④ **它同时是前六个模型的数据补充来源。**

**建议顺序**：模型七（首轮，2 人·天）→ 模型一（8 人·天）→ 视行业选模型四或二 → 成熟后建模型五 → 最后建模型六。

### 打分标准（每维 1—5 分）

| 维度 | 5 分 | 3 分 | 1 分 |
|---|---|---|---|
| **D1 数据可得性** | 台账齐全现成 | 需整理 | 数据基本不存在 |

### 按企业类型调整

| 企业类型 | A 类必建 | 调整说明 |
|---|---|---|
| 原材料密集制造（金属/化工/建材） | 一、七 | 模型一权重最高；模型六提前 |
| 消费电子/家电 | 四、七、一 | 模型四（客户年降）是核心矛盾 |
| 汽车零部件/代工 | 三、二、七 | 质量成本与项目爬坡是主要利润杀手 |
| 多板块集团 | 五、一、七 | 分配公平性优先 |
| 离散制造 + 海外占比高 | 六、一、四 | 模型六可提前到第 3 个 |
| 小微企业（<300 人） | 只建模型一 | 单一链路起步，不铺开 |

### 五条落地纪律

1. **一次只建一个 A 类模型**——并行建两个必然都做不完
2. **先出粗版，2 周一次**——追求完美会导致三个月不出东西
3. **A 类模型必须在 90 天内见效**——见不到钱的管理动作无法存活
4. **B/C 类只在 A 类稳定运行后启动**——判据：A 类连续 3 个月自动更新无异常
5. **每建一个模型，必须先写清「建成后谁做什么决策」**——写不出这句，就不要建

### 90 天见效验证表

| 时间点 | 里程碑 | 验收标准 |
|---|---|---|
| 第 15 天 | 口径签署完成 | 16 份口径单签字率 100% |
| 第 30 天 | 现状镜像粗版完成 | 三段归因合计误差 < 0.05pp |
| 第 45 天 | 因果图完成 + 系数初估 | 节点 ≤25 个，系数有回归输出 |
| 第 60 天 | 阈值规则确定 | ≥3 条可执行规则，含责任人与授权 |
| 第 75 天 | 首次月度更新跑通 | 更新耗时 ≤ 4 小时 |
| 第 90 天 | **产生第一个决策** | **有真实管理动作因模型结论改变，且金额可量化** |

**90 天内没有产生「因模型结论而改变的决策」→ 停止扩张，回到起点重做。**

## 八、公开数据分析（三级降级）实操

> 手里只有公开财报/招股书、没有企业内部台账时用这一节。
> 结论一律标注「仅供讨论，不作决策依据」，但**方法本身可以很硬**。

### 8.1 三个能立刻产生结论的交叉校验

公开数据虽粗，但**口径之间的差额方向本身就是信号**。以下三招屡试有效。

#### 校验一：归母净利 vs 扣非净利，看谁大

| 情况 | 含义 | 处理 |
|---|---|---|
| 归母 > 扣非 | 靠补贴/资产处置增厚利润（**多数公司**） | 归母数虚高，用扣非看真实经营 |
| **归母 < 扣非** | 存在非经常性**损失**（股份支付、减值等） | **归母数低估经营能力**，但一次性因素消退后报表会重构，不可线性外推 |

**示例（某科创板公司 2025，数字为虚构示例）**：扣非 2.4 亿 > 归母 1.1 亿，差 1.3 亿（指向股份支付）。
归母数只有扣非数的 46% —— 只看归母会显著低估其盈利能力。

#### 校验二：毛利减掉最大费用项，看还剩多少缓冲

```
毛利 − 研发（费用化）− 已披露的其他费用 = 余额
余额 ÷ 营收 = 可供其他费用使用的比例
```

**余额薄 = 费用端尚未展开 = 未来利润有下行压力。**

**示例（数字为虚构示例）**：毛利 6.2 亿 − 研发 1.4 亿 = 4.8 亿；
扣非 2.4 亿；**余额仅 2.4 亿**要覆盖全部销售+管理费用。
而次年上半年销售费用已达 1.6 亿（同比翻倍以上）。
→ **预测 2026 利润下滑的钥匙在这里，不在收入端。**

#### 校验三：应收账款增速 vs 营收增速

应收账款增速持续显著高于营收增速 → 增长质量存疑（放宽信用换收入）。
**示例（数字为虚构示例）**：应收 +186% vs 营收 +94%。

### 8.2 单台经济性测算（单价 × 销量型商业模式通用）

**这一招能直接算出「价格战打到哪里公司就亏损」。**

```
单台费用摊销 = 期间费用总额 ÷ 销量
盈亏平衡单价 = 单台费用摊销 ÷ 毛利率
```

**关键规律：规模每翻一倍，盈亏平衡线减半**（因为单台费用与销量成反比）。

| 销量 | 单台费用摊销 | 盈亏平衡单价（毛利率 60%） |
|---|---|---|
| 5,000 | 16.00 万 | 26.67 万 |
| 15,000 | 5.33 万 | **8.89 万** |
| 30,000 | 2.67 万 | 4.44 万 |
| 50,000 | 1.60 万 | 2.67 万 |
| 100,000 | 0.80 万 | 1.33 万 |

（以期间费用合计 8 亿为例）

**推论模板**：
> 在〔X〕万台规模、〔Y〕% 毛利率下，盈亏平衡单价约〔Z〕万元。
> 当前最低售价〔W〕万元，距离底线〔Z−W〕万元。
> **规模需达到〔N〕万台，平衡线才能压到当前最低售价之下。**

**适用场景**：机器人、汽车、家电、SaaS 席位、任何「单价 × 销量」的生意。

### 8.3 价格-销量敏感性（识别「量增价跌」陷阱）

把 ASP 下行与销量上行放在一张表里，看**收入**是否真的增长：

| 情景 | 均价 | 销量 | 收入 |
|---|---|---|---|
| 基期 | 16.64 | 5,500 | 9.15 |
| 量增价平 | 16.64 | 15,000 | 24.96 |
| **价跌 3 成** | 10.00 | 15,000 | 15.00 |
| **价跌 5 成** | 8.00 | 15,000 | **12.00** |

**判据**：若「价跌 5 成 + 量增 173%」的收入 ≈ 基期，说明**价格下行会吞掉全部量的增长**。
此时「以价换量」的叙事不成立。

### 8.4 场景结构审视（判断「收入是否等于商业化」）

拿到收入结构后，按**客户是否算 ROI** 分类：

| 客户类型 | 采购动机 | 复购 | 收入性质 |
|---|---|---|---|
| 科研教育 | 发论文、搭平台 | 一次性 | 项目制 |
| 文娱/展示 | 表演、宣传 | 弱 | 项目制 |
| 政府/示范 | 政策、补贴 | 依赖预算 | **补贴性** |
| **工业/商业** | **替代人工、算 ROI** | **强** | **经营性** |

**若前三类占比 > 60%，说明收入的可持续性未经真实检验。**
**唯一的验证指标：非关联客户是否用经营预算进行重复采购。**

### 8.5 三级降级报告的必备声明

交付时**必须**包含（否则不合格）：

1. **明示这是三级降级分析**，结论「仅供讨论，不作决策依据」
2. **逐条标注置信度**：回归级 / 专家估计·已验证 / 专家估计·待验证
3. **列出所有推演假设**（如「期间费用约 8 亿」是推演值而非披露值）
4. **说明升级路径**：拿到哪几样内部数据后，哪些结论可以从「估计」升为「回归级」

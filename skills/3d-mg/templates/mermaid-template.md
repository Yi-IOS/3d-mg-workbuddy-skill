# 3D-MG Mermaid 图模板

> 模型在产出诊断报告时，可直接复制下面任一代码块，填成本公司的变量。
> 两种用法：
> ① **写进 HTML 汇报文档**：在 `templates/report-template.html` 的 `blocks` 里加一个
>    `{ "t": "mermaid", "code": "此处放 Mermaid 源码" }` 的条目，模板已内置 Mermaid 渐进增强渲染；
> ② **生成 PNG**：把源码存成 `.mmd`，跑 `python3 scripts/gen_flowchart.py 图.mmd -o 图.png`。

## 模板 1：三层镜像工作流

```mermaid
flowchart LR
    A[现状镜像<br/>事实层·每月] --> B[因果镜像<br/>关系层·季度]
    B --> C[推演镜像<br/>选择层·半年]
    C --> D[MTP / 预算 / 经营计划]
    D -->|执行结果| A
    B -.结构化专家访谈.-> B
```

## 模板 2：完整线性因果网络图（主干 · 通用骨架）

> 节点约定：E=外生变量，M=中间变量，D=决策节点，O=经营结果。
> 箭头标注：`符号[弹性量级][时滞]`。例：原材料价 `-->|+0.45 / 2月|` 单位材料成本。

```mermaid
graph LR
    subgraph 外生变量层
        E1[E1 原料价] --> E2[E2 能源物流]
        E3[E3 汇率利率] --> E4[E4 需求景气]
        E6[E6 政策合规] --> E7[E7 突发外部事件]
    end
    E1 -->|锁价比例x%| M1[材料成本]
    E4 --> M6[订单量]
    E7 --> D4[稼动决策]
    M1 --> M2[单位制造成本]
    M6 --> M2
    M2 --> M5[综合毛利率<br/>核心枢纽]
    M5 --> O2[毛利额] --> O3[EBIT] --> O4[经营现金流] --> O5[ROIC]
    D4 --> M7[稼动率] --> M2
```

## 模板 5：偏差三分类 → 处置

```mermaid
flowchart TD
    偏差出现 --> 分类{归因分类}
    分类 -->|执行型| A[纠偏动作·责任到部门·不动MTP]
    分类 -->|外生型| B[预案执行·条件化目标]
    分类 -->|设定型| C[上会·需证据]
    C --> C1[修正目标值]
    C --> C2[修正实现路径]
    C --> C3[暂缓目标·附重估点]
```

## 因果链标注规范（写进任何图都适用）

```
变量A --符号[弹性量级][时滞]--> 变量B
例：原材料价格 --+[高0.45][Δt=2月]--> 单位材料成本
    稼动率      --−[高0.42][Δt=1月]--> 单位固定成本
```

- 符号：`+` 同向 / `−` 反向；弹性量级：高 / 中 / 低；时滞 `Δt=`（月）。
- 决策节点用 `D` 标、外生变量用 `E` 标、最终经营结果用 `O` 标。
- 断点（Bottleneck）用红色高亮框单独标出，是报告最关键的一张图。

> **免责声明**：图中数字若为单位示例，仅用于演示方法论，不代表任何具体企业；真实诊断须以公司正式披露为准。
